# Instructional Design | Interactive Simulations

A collection of interactive, scenario-based learning experiences designed to strengthen decision-making, critical thinking, and workplace performance.

## Featured Simulations

### 01 | Navigating Complex Workflows

A branching customer-complaint simulation where learners navigate competing priorities, evaluate information, and experience the consequences of operational decisions.

**Focus:** Investigative judgment, workflow navigation, and decision-making.

### 02 | Human in the Loop

An AI-assisted decision-making simulation where learners review a recommendation, verify supporting evidence, select an appropriate action, and justify their decision.

**Focus:** AI literacy, evidence evaluation, human oversight, and decision quality.

## Design Approach

Each simulation emphasizes realistic workplace decisions, meaningful consequences, targeted feedback, and opportunities to apply judgment rather than simply recall information.

**Tools:** Twine (Harlowe), HTML, CSS, GitHub Pages.

*Independent portfolio projects using fictional scenarios and data.*
